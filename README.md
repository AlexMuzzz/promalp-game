# Промальп: Стекломой

Небольшая 2D-игра для Telegram Mini App: моем окна, уклоняемся от кирпичей и чаек, сдаём объект и улучшаем снаряжение.

**Играть:** https://alexmuzzz.github.io/promalp-game/

## Запуск

В корне репозитория:

```sh
python3 -m http.server 8765
```

Открыть http://localhost:8765. Сборка и установка зависимостей не нужны. `index.html` — точка входа. Canvas, CSS и ES modules работают напрямую в современных браузерах и Telegram WebView. Основной формат — вертикальный экран; мышь тоже поддерживается.

## Правила MVP

- 6 этажей, по 3 окна; $10 за окно, $180 за полный объект.
- Удерживать палец/мышь и наносить пену. Покрытие считается по сетке 12 × 18 ячеек, повторное движение по одному месту не приближает остальное окно к очистке.
- При 100% покрытия отпустить палец: автоматическая стяжка сверху вниз. Частично нанесённая пена остаётся до конца попытки.
- После трёх окон персонаж спускается. За каждый завершённый этаж, включая выход на землю, основная верёвка теряет 1 прочность и проверяется риск обрыва 2%. На 0 прочности обрыв гарантирован.
- Запасная верёвка ловит один раз и становится основной с прочностью 20/20. При потере последней выдаётся бесплатная базовая, попытка заканчивается.
- Каска принимает 1/2/3 удара в зависимости от уровня, следующий удар вызывает падение. Перед следующей попыткой каска восстанавливается.
- Перед опасностью появляется предупреждение. Во время автоматической стяжки, спуска, меню и паузы опасности не движутся. После попадания — 2 секунды неуязвимости.
- Падение обнуляет только несданный заработок, затем действует пауза 3 секунды. Постоянный баланс и улучшения остаются.
- «Сдать объект» переносит заработок в кошелёк. После этого открывается магазин.
- При закрытии игры незавершённая попытка не восстанавливается. Уже сохранённые износ, покупки и выплаты сохраняются.

## Сохранения и Telegram

Подключён официальный Telegram WebApp SDK; при запуске вызываются `ready()` и `expand()`. При поддержке API отключается конфликтующее сворачивание вертикальным свайпом, настраиваются цвета и виброотклик. При потере фокуса/скрытии страницы игровая попытка ставится на паузу.

В Telegram: `Telegram.WebApp.CloudStorage`, ключ `promalp_save`, на пользователя и бота:

```json
{"balance":0,"ropes":1,"ropeDurability":20,"helmetLevel":1,"squeegeeLevel":1}
```

Загрузка асинхронная. Износ/обрыв сохраняются на каждом спуске, покупки — сразу, доход — по кнопке сдачи. До подтверждения записи операция блокирует управление; ошибка предлагает повторить **тот же снимок**, чтобы не начислять/списывать деньги дважды. Ошибка чтения или повреждённый JSON никогда не заменяются пустым сохранением. Для облачного API нужен Telegram с поддержкой WebApp API 6.9+.

В обычном браузере используется отдельный ключ `promalp_browser_save_v1` в localStorage. Он не переносится в Telegram и не используется вместо облачного сохранения при ошибке. При запрете локального хранилища показывается ошибка.

Это клиентский MVP без сервера, реальных платежей и таблицы лидеров. Он не защищает виртуальный баланс от редактирования клиентом и не обеспечивает транзакции между одновременно открытыми сессиями. Для соревновательной экономики понадобится сервер с проверкой Telegram initData и серверным учётом баланса.

## Файлы и проверки

- `game.js` — экраны, ввод, игровой цикл и процедурная графика Canvas.
- `core.mjs` — правила экономики, износа и покрытия пеной.
- `storage.mjs` — загрузка/запись и изоляция хранилищ.
- `tests/` — тесты правил, хранилища и сценарии игрового модуля с имитацией DOM/Canvas.

```sh
node --check game.js
node --test tests/*.test.mjs
```

Проверяются полный объект, одна выплата, покупки, сохранение после перезагрузки, каска/падение, страховка, износ, пространственное покрытие пены, pause/cancel/multitouch, ошибки чтения/записи и повтор операции. Имитация Telegram не заменяет проверку на реальном телефоне: запустить через кнопку бота, сдать объект, купить улучшение, закрыть и открыть приложение; проверить сохранённый баланс и экипировку.
