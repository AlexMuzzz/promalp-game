# Промальп: Стекломой

Небольшая 2D-игра для Telegram Mini App: моем окна, уклоняемся от кирпичей и чаек, сдаём объект и улучшаем снаряжение.

**Играть:** https://alexmuzzz.github.io/promalp-game/

## Запуск

В корне репозитория:

```sh
python3 -m http.server 8765
```

Открыть http://localhost:8765. Сборка и установка зависимостей не нужны. `index.html` — точка входа. Canvas, CSS и ES modules работают напрямую в современных браузерах и Telegram WebView. Основной формат — вертикальный экран; мышь тоже поддерживается.

## Обновление v2: спуск на ходу, профиль и музыка

- Альпинист автоматически спускается с постоянной скоростью 23 игровых пикселя/с. Фасад плавно движется вверх; отпускание пальца не останавливает спуск.
- Управление только по горизонтали: удерживать и двигать палец/мышь, либо стрелки / A / D. Мытьё происходит автоматически по траектории **персонажа**, а не удалённого указателя.
- 6 этажей, по 3 окна. До $10 за окно пропорционально очищенной площади (округление до целых долларов), до $180 за объект. Неочищенные части остаются грязными и не задерживают спуск.
- Более широкий склиз увеличивает полосу очистки. Весь объект занимает около 82 секунд при стандартной высоте окна, без учёта пауз и сохранений.
- Каска принимает 1/2/3 удара по уровню. Следующий удар приводит к падению; после попадания 2 секунды неуязвимости. Кирпичи и чайки продолжают лететь во время мытья.
- Каждый пройденный этаж расходует 1 прочность основной верёвки и имеет риск обрыва 2%. На нуле обрыв гарантирован. Страховочная спасает один раз и становится основной с прочностью 20/20.
- При падении несданные деньги сгорают, постоянный кошелёк остаётся. После потери последней верёвки выдаётся базовая бесплатно; каска восстанавливается перед попыткой. Повторный старт после падения доступен через 3 секунды.
- Внизу кнопка «Сдать объект» сохраняет заработок и открывает магазин. Износ сохраняется на каждом этаже; покупки — сразу. При закрытии незавершённая попытка теряется.

### Мой альпинист

Профиль открывается из главного экрана, магазина и кнопкой в шапке вне спуска. В нём — имя из Telegram (или «Высотник» в браузере), общая фигурка, реальное снаряжение и гардероб. Примерка бесплатна; покупка сразу надевает образ. Купленные образы можно переключать бесплатно. В профиле и игре используется один Canvas-рендерер персонажа.

| --- | ---: | --- |
| Сменщик | Бесплатно | Рабочая куртка и жёлтая каска |
| Ночная смена | $120 | Фиолетовый костюм, неоновые полосы и визор |

Скины косметические: не дают дополнительной защиты или заработка.

### Музыка и эффекты

Оригинальная зацикленная чиптюн-мелодия (112 BPM, две вариации) синтезируется Web Audio API: square-мелодия, triangle-бас, арпеджио и мягкая перкуссия. Аудиофайлы и внешние треки не загружаются. Есть короткие сигналы монет, покупки, удара, падения, старта и сдачи объекта.

Музыка начинает играть только после действия пользователя. Кнопка ♫ управляет музыкой и эффектами; настройка хранится локально в `promalp_sound`. Пауза и скрытие страницы останавливают звучание. Без поддержки Web Audio игра продолжает работать без звука. Поведение запуска соответствует [рекомендациям Web Audio](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices#autoplay_policy).

## Сохранения и Telegram

Подключён официальный Telegram WebApp SDK; при запуске вызываются `ready()` и `expand()`. При поддержке API отключается конфликтующее сворачивание вертикальным свайпом, настраиваются цвета и виброотклик. При потере фокуса/скрытии страницы игровая попытка ставится на паузу.

В Telegram: `Telegram.WebApp.CloudStorage`, ключ `promalp_save`, на пользователя и бота:

```json
{"balance":0,"ropes":1,"ropeDurability":20,"helmetLevel":1,"squeegeeLevel":1,"ownedSkins":["worker"],"equippedSkin":"worker"}
```

Старые сохранения без полей скинов автоматически получают `ownedSkins: ["worker"]` и `equippedSkin: "worker"`, сохраняя весь прежний баланс и снаряжение. Загрузка асинхронная. Износ/обрыв сохраняются на каждом спуске, покупки — сразу, доход — по кнопке сдачи. До подтверждения записи операция блокирует управление; ошибка предлагает повторить **тот же снимок**, чтобы не начислять/списывать деньги дважды. Ошибка чтения или повреждённый JSON никогда не заменяются пустым сохранением. Для облачного API нужен Telegram с поддержкой WebApp API 6.9+.

В обычном браузере используется отдельный ключ `promalp_browser_save_v1` в localStorage. Он не переносится в Telegram и не используется вместо облачного сохранения при ошибке. При запрете локального хранилища показывается ошибка.

Это клиентский MVP без сервера, реальных платежей и таблицы лидеров. Он не защищает виртуальный баланс от редактирования клиентом и не обеспечивает транзакции между одновременно открытыми сессиями. Для соревновательной экономики понадобится сервер с проверкой Telegram initData и серверным учётом баланса.

## Файлы и проверки

- `game.js` — экраны, ввод, игровой цикл и процедурная графика Canvas.
- `core.mjs` — правила экономики, износа и покрытия пеной.
- `avatar.mjs` — общая фигурка и внешний вид трёх скинов.
- `audio.mjs` — оригинальная музыка, эффекты и управление звуком.
- `storage.mjs` — загрузка/запись и изоляция хранилищ.
- `tests/` — тесты правил, хранилища и сценарии игрового модуля с имитацией DOM/Canvas.

```sh
node --check game.js
node --test tests/*.test.mjs
```

Проверяются автоматический проход всех этажей, частичная оплата, удержание пальца между этажами, пауза, каска/падение, страховка, износ, миграция старых сохранений, примерка и покупка скинов, бесплатное переключение купленных образов, отсутствие двойных списаний, ошибки облака, изоляция браузерных сохранений, запуск/отключение/пауза аудио и единственный звуковой планировщик. Имитация Telegram не заменяет проверку на телефоне: запустить через кнопку бота, сдать объект, купить образ, закрыть и открыть приложение; проверить сохранённый баланс, образ и экипировку, а также звук после первого касания и тишину при сворачивании.
